# Tetris con Matrices — Lección 6: Líneas, puntuación y fin del juego

Esta rama corresponde a la **Lección 6**. ¡El Tetris ya es jugable de principio a
fin! Las filas completas **desaparecen**, sumas **puntos** y el juego **termina**
cuando el tablero se llena. Todo esto todavía en modo **números**.

## Qué aprenderás
- Detectar y eliminar filas completas, desplazando el resto hacia abajo.
- Sumar puntos según cuántas líneas eliminas a la vez.
- Detectar el fin del juego y reiniciar.

## Instalar y ejecutar

```bash
pip install -r requirements.txt
python main.py
```

Controles: ← → mover, ↑ rotar, ↓ bajar, R reiniciar (al terminar), Esc salir.
