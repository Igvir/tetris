# Sonidos del juego

Coloca aqui los archivos de sonido que usa el Tetris:

- `giro.wav` — sonido corto al rotar una pieza con exito.
- `linea.wav` — sonido al eliminar una o mas filas completas.

Los sonidos son **opcionales**: si estos archivos no existen, el juego
funciona igual, simplemente sin audio (degradacion segura). Puedes usar
cualquier archivo `.wav` corto y ligero; solo respeta los nombres de arriba.
